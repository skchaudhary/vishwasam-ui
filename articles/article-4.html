A practical guide to on-page SEO for small sites

Published: Aug 15, 2026

For small sites and independent publishers, on-page SEO is the highest-leverage work you can do to improve discoverability. This guide focuses on practical edits that you can make quickly to improve how search engines read and rank your pages.

Title tags and meta descriptions

Make sure every page has a unique title under ~60 characters and a meta description around 120–160 characters. Use descriptive language and include a main keyword naturally. Titles should reflect the page's main purpose.

Readable URL structure

Use short, human-readable URLs that include the target keyword where sensible: /articles/how-to-publish-github-pages is better than /post?id=1234. Avoid changing URLs frequently — use redirects if you must move content.

Headings and content structure

Use a single <h1> per page for the main title and <h2>/<h3> for subsections. Break content into short paragraphs, bullet lists, and numbered steps to improve scanning on mobile devices.

Include meaningful, original content

Pages should provide real value — actionable steps, examples, or original analysis. Aim for 500+ words on core pages and ensure the first 100–150 words summarize the key point; search engines often use this snippet.

Ensure crawlability

Serve important content in static HTML where possible. If you use client-side JavaScript to render page content, provide server-rendered snapshots or pre-rendered HTML to ensure crawlers can see the content without executing scripts.

Robots and sitemap

Keep robots.txt permissive (no Disallow for your main pages) and publish a sitemap.xml listing important URLs. This helps Google find and index pages faster.

Measure and iterate

Use Search Console to inspect URLs and see indexing status. Pay attention to organic queries and tweak titles and content to improve click-through rates. Over time, add internal links between related pages to improve navigation and indexing.

Following these steps will make your site more discoverable and ready for ad network reviews. Once your content is published and stable, request the AdSense review.
