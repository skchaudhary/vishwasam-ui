How to set up a simple static site

Published: Aug 15, 2026

This guide shows the basic steps to create a minimal static website and publish it using GitHub Pages. It covers creating HTML files, adding a CNAME for a custom domain, and ensuring the site is crawlable for services like Google AdSense.

Steps

  1. Create HTML pages and a `docs/` folder in your repository.
  2. Add a `CNAME` file with your custom domain.
  3. Ensure `robots.txt` allows crawling and add a `sitemap.xml`.
  4. Commit and push to GitHub; enable Pages from the `docs/` folder.
  5. Verify the site is publicly reachable and returns HTTP 200 for important pages.
